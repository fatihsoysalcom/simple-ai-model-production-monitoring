# Simple AI Model Production Monitoring

This example demonstrates a basic approach to monitoring an AI model in a simulated production environment. It includes a simple "AI model" that makes predictions, logs input and output, and tracks performance metrics like latency and a simulated accuracy (Mean Absolute Error). It also shows a rudimentary concept of detecting "model drift" by observing changes in prediction patterns or performance over time, simulating a scenario where the real-world context shifts.

## Language

`python`

## How to Run

Save the code as `main.py` and run from your terminal:
`python main.py`
